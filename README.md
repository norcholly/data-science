# Data Science

This repository is a collection of data science projects focused on data analysis, visualization, and exploratory data analysis (EDA).

## Contents

- **datasets/**
  Contains datasets used in the projects:
  - `cause_of_deaths.csv`
  - `smoking_health_data_final.csv`
  - `turkey_gdp_analysis.csv`
  - `tr-verimlilik-analizi-v1.xlsx`

- **eda-works/**
  Jupyter notebooks for exploratory data analysis and insights:
  - `cause_of_deaths.ipynb`
  - `smoking_health_data_final.ipynb`
  - `tr-verimlilik-analizi-v1.ipynb`
  - `turkiye_economic_growth_analysis.ipynb`

## Purpose

The goal of this repository is to practice and demonstrate skills in:
- Data cleaning
- Exploratory data analysis (EDA)
- Data visualization
- Basic statistical analysis
